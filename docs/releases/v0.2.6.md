# Codex App Server WebUI v0.2.6

This patch release makes long-running sessions easier to read and ensures that the first message
in a newly created thread reaches app-server without depending on rollout-file timing.

## Compact completed turns

The Web UI now groups messages by their native app-server turn identity. After a run completes, it
keeps the user prompt and final assistant response visible while collapsing intermediate progress,
tool calls, and tool output behind an expandable summary. Active turns remain fully expanded.

Previously loaded history pages also remain visible while the selected session refreshes, so live
updates no longer replace older messages with only the newest page.

## Completion metadata

Completed-turn summaries show elapsed time and the final cumulative token-usage snapshot reported
by app-server. Memory citations are parsed into structured source and note fields, then rendered as
compact metadata instead of exposing the internal citation wrapper in message text.

These additions raise the typed Bridge protocol version from 22 to 23. Existing fields and request
shapes remain compatible; clients that understand protocol 23 can use the optional turn and
metadata fields.

## Reliable first messages

Sending the first message to an empty, newly created thread now starts a native `turn/start`
request directly with the selected thread ID, composer input, and client message ID. The request no
longer waits for a rollout path that does not exist until the first turn starts.

## Upgrade and deployment

The release changes Bridge, its embedded Web UI, and the browser demo only. A normal Bridge hot
deployment can preserve and adopt the healthy managed app-server process; no app-server argument
change or intentional app-server restart is required for this upgrade.

## Validation

- The release WASM demo, JavaScript regression suite, and Vite production bundle build and pass.
- The complete Rust workspace test suite passes, including empty-thread turn startup, turn usage,
  memory citation, browser notification, interruption, cursor-stability, and Desktop compatibility
  coverage.
- Rust formatting, frontend formatting, and all-target, all-feature Clippy pass with warnings
  denied.
