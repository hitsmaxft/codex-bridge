# Codex App Server WebUI v0.2.1

This patch release fixes the displaced mobile composer caret and button hit targets reported in
Firefox on iOS. It also makes the README and project page shorter by removing repeated product and
use-case descriptions.

## Firefox iOS composer stability

Firefox on iOS uses WebKit, where native selection overlays can temporarily diverge from a fixed
input control during keyboard and visual-viewport animation. The composer previously reacted to
every `window` and `visualViewport` resize by resetting the focused textarea to its minimum height,
measuring it, and writing a new height. That introduced an avoidable intermediate layout while the
browser was already repositioning the keyboard viewport.

The mobile composer now:

- uses the iOS system font with an exact `16px` font size, `20px` line height, and symmetric
  vertical padding;
- explicitly removes transform, filter, perspective, and `will-change` effects from the input
  coordinate chain; and
- leaves a focused textarea untouched during viewport-resize events while retaining normal
  content-driven growth and the existing document-scroll behavior.

The fix was confirmed on the affected Firefox iOS setup.

## Documentation

The README now provides one concise product definition followed by a four-item capability summary.
The project page uses its hero for positioning and replaces the repeated use-case section with the
shared task model, structured tool visibility, and complete Queue/Steer/Stop workflow.
