# Codex App Server WebUI v0.3.6

This release improves how conversations are written and read:

- Large pasted text becomes a file attachment that can be reopened from the conversation.
- Slash commands and skills have a selection panel in the composer.
- Computer-use results support multiple screenshots. Choose an image from the message preview, or
  see images beside their tool calls and inside expanded results.
- Turn folding, token usage, message card styling, and scrolling are more stable while activity
  streams in or details expand.

The release WASM demo, browser regression suite, production Web UI build, and Rust workspace tests
pass. The local Bridge was verified with its managed app-server and authenticated HTTP endpoint.

See the [installation guide](../install.md) and [release history](./).
