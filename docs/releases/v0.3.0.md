# Codex App Server WebUI v0.3.0

Version 0.3.0 turns the Web UI from a remote conversation view into a fuller session workspace.
The release centers on two things: bringing more native Codex session capabilities into one typed
interface, and adding new tools for reading, exploring, and branching from ongoing work.

## Codex-aligned session controls

- A live goal panel shows objective, status, elapsed time, and token budget, with typed pause,
  resume, and edit actions.
- Active-turn state, Queue, Steer, Stop, model, and reasoning-effort controls share the same
  app-server-backed session view.
- Structured tool calls, command output, file diffs, token usage, memory citations, and pending work
  remain attached to the conversation instead of being flattened into plain text.
- Session tools expose cached run time, turn and tool counts, token totals, rollout-sequence health,
  and explicit maintenance controls.
- Runtime architecture reflects the managed app-server, Desktop interposition, and selected voice
  backend directly from live Bridge state.

## New reading and exploration tools

- A composer-free full-screen mode turns conversation history into a dedicated reading surface.
- One action collapses every expanded message in the session; another clears the current browser
  cache and reloads the newest server window.
- Selecting text exposes copy, insert, and temporary-conversation actions. A selected passage can
  become the context for an isolated full-screen conversation without leaving the original task.
- Workspace links open in a typed preview before download, with Markdown, text, image, and binary
  presentation chosen by the Bridge.
- Tool-result images open in a dedicated zoomable viewer while remaining part of their structured
  message and turn.

## A workspace for long sessions

- First entry fetches and renders the newest bounded message window immediately.
- Completed turns keep compact summaries, while full intermediate text and tool details load only
  when the reader expands that turn.
- Task overview, session statistics, and bounded server-side caches make large rollouts useful
  without transferring or parsing the entire history in the browser.
- Incremental session updates extend the visible tail while preserving the reader's current place
  across desktop and mobile layouts.

## Bridge and protocol

- Protocol version 34 adds typed goal, session-statistics, file-preview, repair, and managed-service
  control paths used by the expanded Web UI.
- Session parsing and bounded caches provide the recent window, deferred turn details, task
  overview, and statistics without making the browser rescan a complete rollout.
- The one-writer safety model from v0.2.10 remains in place: Bridge-managed app-server ownership is
  scoped to the configured Codex history store and competing private writers are not terminated.

## Validation

- The release WASM demo and browser regression suite cover session controls, large-session paging,
  the reading workspace, file preview, temporary conversations, and runtime presentation.
- The complete Rust workspace suite, formatting checks, strict all-target/all-feature Clippy, and
  macOS/Linux installer syntax checks pass from the release source.
- Production Web UI assets and the optional whisper-enabled release daemon are rebuilt from the
  final tagged source before deployment.
