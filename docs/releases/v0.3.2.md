# Codex App Server WebUI v0.3.2

Version 0.3.2 makes long-running Codex sessions feel like one coherent live conversation, expands
the workspace artifact experience, and gives self-hosted instances a clearer identity.

## Coherent live activity

- Snapshot refreshes and WebSocket events reconcile into one logical running turn instead of
  presenting completed snapshot fragments and new activity as unrelated groups.
- The final active tool group updates incrementally while earlier tool groups remain attached to
  their original messages.
- Expanded tool details, user disclosure choices, keyboard focus, and viewport anchors survive
  incremental updates.
- Compact activity keeps the latest polling state for subagent waits and asynchronous stdin reads,
  while named subagent conversations remain directly inspectable.
- Live turn usage stays concise and includes token, cache, and tool progress before completion.

## Long-session reading

- Initial navigation opens the newest bounded message window without replaying an entire long
  rollout from its beginning.
- Returning to a session supplements the existing timeline incrementally and presents explicit
  history-loading state only while older or missing data is being reconciled.
- Mobile bottom-follow behavior remains stable as tool calls and model output extend the current
  turn, while readers browsing older content retain their position.
- Floating previous/next turn controls, long-reply disclosure, and completed-turn summaries make
  very large conversations easier to scan.

## Workspace artifacts

- The in-page file viewer supports HTML alongside text, Markdown, and content-detected images.
- Explicit Markdown image tags in final replies render as image controls without duplicating
  ordinary file links.
- Image preview supports canonical files under `/tmp` while retaining workspace boundaries,
  regular-file checks, content-based image validation, and the 16 MiB limit.
- Workspace downloads use short-lived tickets and Codex app-server file reads when the background
  service cannot directly access a macOS protected folder.

## Self-hosted identity and transport

- `web_ui.name` customizes both the browser title and the top-left brand label for each deployment.
- Optional direct HTTPS accepts a configured PEM certificate chain and private key.
- Versioned static assets remain cacheable through remote proxies while the HTML entry stays
  revalidated, and the Bridge keeps expensive session lookup work off ordinary file-link clicks.

## Validation

- The production WASM demo and browser regression suite cover live tool grouping, disclosure
  preservation, viewport reconciliation, image/file rendering, and the current composer state.
- The complete Rust workspace suite and production Vite build pass from the release source.
- Real ZIP and EPUB artifacts in a macOS protected workspace complete preview-ticket and download
  flows with byte-for-byte and SHA-256 equality.
