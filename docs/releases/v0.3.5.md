# Codex App Server WebUI v0.3.5

This patch release fixes a mobile session-list flicker. Archive buttons stay hidden while you
scroll vertically and appear only during or after a deliberate right swipe. Scrolling also closes
an archive action that was left open.

The browser regression suite, production Web UI build, and Rust workspace tests pass.
