# Codex App Server WebUI v0.3.4

This release adds a floating card for Codex clarification questions. You can answer a suggested
choice or enter your own response while Codex continues other work. The card can be collapsed and
restored.

Answers return to the running conversation. If that run has ended, the card clearly offers to
continue in a new turn. Unanswered questions reappear when you reopen the session.

The release WASM demo, browser tests, production Web UI build, Rust workspace tests, and formatting
checks pass.

See the [installation guide](../install.md) and [release history](./).
