# Codex App Server WebUI v0.2.9

Version 0.2.9 makes remote queue management more reliable, keeps live sessions visually stable,
and adds an explicit recovery path for damaged local rollout sequences.

## Reliable remote work

- Multiple text-only Queue entries can be merged from the pending-message menu while preserving
  their server order.
- Chats now keeps a visible new-session action even when empty and starts threads without a project
  assignment; project sessions retain their existing directory and optional worktree choices.
- Worktree creation now runs as a bounded Bridge job. The UI immediately renders a project
  placeholder and polls its handle without blocking navigation, then opens the completed session.
- Merge uses the native app-server queue as its authority and rolls back safely if a concurrent
  queue change prevents completion.
- Composer focus stays within the actual input shell; interacting with pending-message menus no
  longer redirects focus to the textarea.
- A damaged rollout ordinal sequence can be repaired explicitly from the session tools. The Bridge
  stops its managed app-server, preserves every valid JSONL event, creates a backup, rewrites only
  the affected ordinal sequence, and restarts the service.

## Stable live sessions

- Running tool updates use a stable bottom anchor instead of repeatedly starting competing smooth
  scroll animations.
- Bounded tool-page caches, per-session parsing locks, and cold-background-load limits reduce work
  when navigating large histories.
- Runtime status remains available through the existing in-memory performance and cache metrics.
- The Bridge accumulates per-session run time, turn count, tool calls, and token totals while it
  parses active or warmed rollouts; Tools renders the cached snapshot without scanning history in
  the browser.

## Product presentation

- The product page now uses real interface renderings for mobile sessions, parallel Tasks, and
  structured tool diffs.
- Release highlights focus on user outcomes instead of repeating individual patch notes.
- The deployment section now illustrates Cloudflare Zero Trust in front of a loopback-only WebUI
  and Bridge, suitable for homelab and NAS installations.
- Mobile clients without browser notification support receive a durable in-app completion toast;
  the composer indicator uses an upward glow that stays behind readable text.

- Full Rust workspace test suite passed.
- Production Web UI assets and the optional whisper-enabled daemon were rebuilt in release mode.
- The deployed daemon reports protocol version 32 and healthy managed components.
