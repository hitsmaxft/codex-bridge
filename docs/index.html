一个会话，多种入口One session, multiple surfaces

不是另一个孤立客户端，而是 Codex 工作流的本地延伸。

Not another isolated client. A local extension of your Codex workflow.

CLI 适合脚本与快捷操作，Web UI 适合手机和另一台局域网设备，桌面 GUI 仍然负责你熟悉的交互。所有写操作都要求明确的会话目标。

Use the CLI for scripts, the Web UI from a phone or another LAN device, and keep the desktop GUI for your normal workflow. Every write has an explicit thread target.

可脚本 CLIA practical CLI

列出和选择会话、读取历史、排队消息、引导或中断活跃任务，以及执行受限的主机命令。

List and select threads, read history, queue messages, steer or interrupt active turns, and run allowlisted host commands.

Project grouping, paged history, Markdown, image attachments, live status, and layered tool arguments and results.

与 GUI 共存Coexists with the GUI

读取 rollout 不抢占 writer；新任务进入 queue；只有活跃 turn 才使用 steer，没有活跃任务时自动改为 send。

Rollout reads do not claim the writer. New work is queued; steer is used only for an active turn and falls back to send when idle.

快速开始Quick start

从本机终端开始，再按需开启 Web。

Start in the terminal. Add the Web UI when you need it.

Terminal
# Build the shared daemon and CLI
$ cargo build --release --locked

# Inspect and select a Codex thread
$ codexctl ls
$ codexctl select <THREAD_ID>
$ codexctl send "Review the current changes"

# Optional private Web UI
$ codex-bridge --web-ui \
    --web-ui-listen 127.0.0.1:18791 \
    --web-ui-password-file ~/.codex-bridge/web-ui-password

局域网不是互联网部署LAN access is not Internet hosting

绑定 0.0.0.0 会向同一网络暴露会话内容和写操作。只应在可信家庭网络使用；跨不可信网络请增加 TLS/VPN，不要直接转发公网端口。

Binding 0.0.0.0 exposes session content and write operations to the local network. Use it only on a trusted LAN; add TLS or a VPN across untrusted networks and never forward it directly to the public Internet.
