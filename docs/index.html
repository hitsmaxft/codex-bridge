Queue / 跟进最终一致Eventually consistent Queue / Steer

稳定的提交 ID 贯穿视觉缓冲区、请求协商、原生队列与最终会话历史； 连续跟进不会再丢失，消息实际执行前会持续保留待处理状态。

Stable submission IDs connect the visual outbox, request negotiation, native queue, and final history without losing repeated follow-ups or clearing pending state early.

事件驱动的实时同步Event-driven live synchronization

app-server WebSocket 事件驱动 activity、缓冲消息和历史记录的局部对账； 只有断流或事件缺口才启用轮询恢复。

App-server WebSocket events drive activity, pending messages, and local history reconciliation, with polling reserved for stream recovery.

长会话与 worktree 稳定性Long-session and worktree stability

全局游标和稳定视口锚点避免缓冲消息残留与页面跳动；Codex worktree 依据 Git common-dir 归入原项目，同时保留真实执行目录。

Global cursors and stable viewport anchors prevent stale outbox entries and scroll jumps, while Git common-dir identity keeps Codex worktrees in their original project.

项目与 Chats 准确归类Project-aware history

Bridge 使用 app-server 的分页项目与会话索引；仓库任务留在项目下， 只有无法匹配项目根目录的对话进入 Chats。

Paginated app-server project and thread indexes keep repository tasks in their projects and place only unmatched conversations in Chats.

稳定的消息局部刷新Stable message updates

未变化的消息节点不再整体重挂；工具展开状态和阅读锚点得以保留， 真正新增消息时才平滑跟随底部。

Keyed reconciliation preserves open tools and the reading anchor; only genuinely new content triggers smooth bottom-following.

Queue / Steer 消息菜单Queue / Steer message menu

每条缓冲消息都可撤回；纯文本 Queue 还可直接改为跟进， 不生成重复消息，也不冒险丢失附件。

Buffered work can be withdrawn, and safe text-only Queue entries can move directly to Steer without duplication.

可靠的停止与归档Reliable Stop and archive

Stop 使用推送中观察到的准确 turn ID；归档时立即移除持久订阅， 避免写盘竞态和重连阻塞。

Stop targets the observed live turn, while archive immediately removes stale reconnect subscriptions.

可点击的受限文件下载Clickable scoped downloads

Markdown 目标和编码后的绝对路径 URL 都会进入五分钟下载票据流程； 工作目录与 16 MiB 安全限制保持不变。

Markdown targets and encoded absolute-path URLs share the same five-minute ticket flow and unchanged workspace boundary.

更轻的对话视觉层级Calmer conversation hierarchy

中性用户气泡、轻量工具摘要和逐条复制按钮让桌面与移动消息视图更接近 ChatGPT。

Neutral user bubbles, lighter tool summaries, and per-message copy controls bring desktop and mobile closer to ChatGPT.

快速开始Quick start

三步启动。

Start in three steps.

Terminal 
# Install as user services (no sudo)
$ ./scripts/install-macos.sh --web-ui
$ ./scripts/install-linux.sh --web-ui

# Runtime choices live in one user config
$ $EDITOR ~/.config/codex-bridge/config.toml

# Inspect and control Codex
$ codexctl ls
$ codexctl select <THREAD_ID>
$ codexctl send "Review the current changes"
远程访问架构Remote access architecture

通过 Cloudflare Zero Trust，把 Codex 安全带到任何设备。

Bring Codex to any device through Cloudflare Zero Trust.

Bridge 与 app-server 只监听本机环回地址；Cloudflare Tunnel 主动建立出站连接，Access 在请求进入家庭网络前完成身份校验。

Bridge and app-server stay on loopback. Cloudflare Tunnel creates the outbound connection, while Access authenticates requests before they reach your homelab.
