快速开始Quick start

三步启动。

Start in three steps.

Terminal
# Build the shared daemon and CLI
$ cargo build --release --locked

# Inspect and select a Codex thread
$ codexctl ls
$ codexctl select <THREAD_ID>
$ codexctl send "Review the current changes"

# Optional private Web UI
$ codex-bridge --web-ui \
    --web-ui-listen 127.0.0.1:18791 \
    --web-ui-password-file ~/.codex-bridge/web-ui-password
